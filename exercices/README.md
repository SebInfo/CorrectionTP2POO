# Corrections séparées

Les fichiers sont à lire dans l'ordre. Les exercices qui utilisent la base
incluent `../connexion.php`. Les exercices 3 à 9 utilisent la classe finale
`../Produit.php` afin d'éviter de recopier inutilement l'entité ; chaque fichier
contient en revanche la méthode du Repository étudiée dans l'exercice.

Lancer un exercice depuis le navigateur, par exemple :

`http://localhost:8888/TP2POO/exercices/01_lire_une_ligne.php`

L'exercice 10 est le mini-projet complet à la racine : `../index.php`.
